# Ноктюрн FM 13.02

Положи сюда свои треки (.opus, а также .ogg, .mp3, .m4a) - и всё.

- `npm start` и `npm run build` сами пересоберут `playlist.json` из файлов этой папки.
- Если меняешь файлы на уже запущенном сервере, выполни `npm run playlist` и обнови страницу.
- Название берётся из имени файла: `Исполнитель - Название.opus`. Номер в начале (`01 `, `02. `) задаёт порядок и в название не попадает.
- Радио стартует со случайного трека, когда гость нажимает «Войти» (браузеры не дают включать звук до первого клика), и дальше идёт по кругу.
